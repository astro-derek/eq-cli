# Feature 0012: Opt-In Axis Labels

## Status
Planned

## Goal
Make axis labels explicitly optional through CLI parameters.

## Requirements
- Axis labels default off unless enabled by parameter.
- Separate control for dB labels and frequency labels.
- Axis baseline remains visible when labels are disabled.

## Acceptance Criteria
- [ ] Frequency labels can be toggled.
- [ ] dB labels can be toggled.
- [ ] Baseline stays aligned in both modes.
- [ ] Tests verify toggle behavior.
